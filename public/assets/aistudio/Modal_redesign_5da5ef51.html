What changed in every modal
  • Bottom sheet on phones, centered dialog from 768px, with a sticky header and a sticky footer.
  • Labels above fields, 48px inputs, ৳ prefix on amounts, required marks and helper text.
  • Related fields grouped in cards; repeatable items get their own card with a remove button.
  • Warnings are banners with an icon and text, not colour alone. Destructive actions use a red button and a reason field.
  • Native dialog: Esc, focus trap and focus return built in.
